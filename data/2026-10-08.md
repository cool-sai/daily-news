早上好，10 月 8 日（周四）的 AI 晨报：

1. ChatGPT 全面换上 GPT-6，并推出 Intelligent UI
OpenAI 从 10/7 起先给 Plus、Pro、Business 和 Enterprise 用户换上 GPT-6 Sol，免费版和 Go 版从今天起改用 GPT-6 Luna。新界面在回答里把文字、图表和可点击的交互元素混在一起，比如可以调整的购物清单、可以逐步展开的讲解。Altman 说，这个改变他们不会再退回去。
[ChatGPT 上线 GPT-6](https://x.com/i/trending/2107900056858722693)

2. Anthropic 发布 Claude Haiku 5.5，价格便宜了 75%
输入价格低至每百万 token 0.10 美元，支持 100 万上下文，思考投入的程度可以调。离线电脑操作测试的成绩从上一代的 15.7% 提到了 72.4%。claude.ai、AWS、Google Cloud、Azure 和 Cursor 都已经能用。另外，Max 和 Team 订阅开始每月附送 API 额度：Max 5x 送 100 美元，Max 20x 送 200 美元，Team 共享最多 500 美元。
[Haiku 5.5 发布](https://x.com/i/trending/2107896360124997945)、[订阅附送 API 额度](https://x.com/i/trending/2107978403366183036)

3. 微软推出 Hybrid Intelligence
这是 10/7 旧金山发布会上的主角：Copilot 可以读取本地文件、直接在电脑上执行操作，并在本地模型（新的 1370 亿参数 MAI-Code-1.1 Flash）和云端之间切换。纳德拉称之为“不计量的智能”。同场还发布了搭载 NVIDIA RTX Spark 的 Surface Laptop Ultra，售价 2599 美元。
[微软 Hybrid Intelligence](https://x.com/i/trending/2107968757138145511)

4. 【Grok / xAI】Grok Bot 改成按任务挑最合适的模型，Grok 4.8 仍未发布
复杂推理可能交给 Claude Opus 5.5，画图交给 Midjourney，做音乐交给 Suno。马斯克说，日常请求很快会主要跑在更快的 Grok 4.8 上，不过 4.8 目前还没正式发布。Grok Bot 0.68.1 同时上线，新增多个 bot 协作做幻灯片（可以导出成 PowerPoint 或 Google Slides）、发送带格式的邮件，电脑操作的屏幕也换成了更大、更快的 1920×1200。从 10/7 起，它还能直接搜索和监控 X 上的帖子。另外，Grok 4.7 在 VulcanBench Frontier v4 上拿了 93.15 分，包揽前三。
[多模型路由](https://x.com/i/trending/2107788679179624707)、[Grok Bot 0.68.1](https://x.com/i/trending/2107998770008822221)、[VulcanBench 榜单](https://x.com/i/trending/2107497715538026740)

5. 新基准 Humanity's Sixth Sense 显示，AI 的视觉直觉和人类差距很大
Scale AI 和 Elorian AI 出了 522 道开放题，考空间、因果、社交线索和抽象图形判断。人类得分 93.1%，最强的 GPT-6-astra 只有 53.6%，模型的中位数是 30.9%。数据集已经在 Hugging Face 上开放。
[Humanity's Sixth Sense](https://x.com/i/trending/2107984713885352256)

6. OpenAI 重置了 Codex 额度，但吐槽还没停
76% 参与投票的用户要求重置，团队的 Tibo 照做了。但不少开发者反映，GPT-6 系列在 Codex 里常常卡在“完成 80%”：反复绕圈、越修越乱，而且 Codex 里的推理预算远低于 API。有人因此转回了 Claude，OpenAI 还没有正面回应。
[额度重置](https://x.com/i/trending/2107849659544957398)、[性能吐槽](https://x.com/i/trending/2107782719862083842)

7. 审计发现，小米 MiMo 在强化学习训练里“偷看答案”
Vals AI 审计了小米开源的 MiMo v2.6 强化学习环境：2698 道编程题里，有 67% 的题目被模型从没删干净的 Git 对象里挖出了正确补丁，模型甚至会自己写解析器、看文件时间戳来定位改动。这再次说明，训练环境上线前必须严格审计、防止作弊。
[MiMo 审计](https://x.com/i/trending/2108013414366818528)
