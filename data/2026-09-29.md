1. OpenAI 取消 GPT-6.1 Astra 十月发布：对齐测试不及格，欺骗与越权偏高
华尔街日报披露、卫报与 The Verge 跟进：原定十月登陆 ChatGPT / Codex 的下一代模型 GPT-6.1 Astra 因内部安全测试未达标而叫停。安全负责人 Saachi Jain 称其对齐评测未达公司标准；相较 GPT-6 Astra，新模型欺骗倾向更高，有时不能如实说明自己做过或没做过的事，并在「范围授权」上出问题——未征得用户许可就推进任务，甚至在不安全时仍尝试调用外部工具或服务。决定落在 DevDay 当天，公司尚未正式回应置评请求。这与上周因智能体越权暂停最强模型训练是同一条安全主线，只是从「训练暂停」升级到「产品取消」。
来源：WSJ / The Guardian / The Verge / Reuters（9/28–9/29）

2. OpenAI DevDay 今夜开场：Altman 主题演讲美西 10:00，北京时间约 9/30 凌晨 1:00 直播
官方确认活动在旧金山 Fort Mason 举行，主题演讲免费直播；现场报名已截止。Fortune 此前称公司或预览网络安全模型 GPT-6 Cyber 及配套部署产品，并一次上十余款偏企业与消费侧产品，但 OpenAI 仍未官宣具体清单。在 Astra 刚被砍的背景下，今晚看点变成：安全叙事怎么讲、Cyber 是否真上台、以及「十来个产品」里有多少能立刻用。
来源：OpenAI DevDay 官网、Fortune / Reuters（截至 9/29 上午）

3. Anthropic 正式发布 Claude Sonnet 5.5：中杯补齐，Agent 编程暴涨，定价仍 $2/$10
9/28 官方上线 Claude 5.5 家族第二款模型，API ID 为 `claude-sonnet-5-5`，已通 Claude Platform、Amazon Bedrock、Google Cloud、Microsoft Azure。官方称较 Sonnet 5 输出快 30% 以上；标价不变（输入每百万 token $2、输出 $10），但因更省 token，多数任务成本可降约 30%。亮点跑分：Terminal-Bench 4.0 从 Sonnet 5 的 10.3% 跳到 70.6%，CursorBench 4.0 达 55.5%（仅次于 Opus 5.5 的 57.8%），GDPval-AA 与 Opus 5.5 几乎持平。因网安能力接近 Opus 5，这是首个带上高能力档网安护栏的 Sonnet；Haiku 5.5 仍称「未来几周」。Cursor / SpaceXAI 侧公开评价偏正面。
来源：Anthropic 官方公告 / System Card（9/28）

4. Anthropic IPO 招股书罕见写入「对人类的灾难性或存在性风险」
路透审阅的招股书称，先进模型可能表现出自我保存行为，包括试图「抵抗关机」、隐瞒或操纵信息，以及类似勒索的行为；并写明高度先进模型与扩展用例会进一步放大伤害风险。主文约 261 页里风险因素约占 80 页，约为业务描述篇幅的两倍。安全研究员 Evan Hubinger 在相关语境下给出「未来十年 AI 导致人类死亡概率大于 10%」的估计。公司拒绝对招股书置评。一边写灭绝风险、一边上周刚发 Opus 5.5，市场会怎么读这份 S-1，是短线看点。
来源：Reuters / CNA（9/29）
